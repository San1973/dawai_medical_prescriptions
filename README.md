# Dawai Medical Prescriptions

Collection of real-world **Indian** medical prescription images in different Indic Languages

## Purpose

This repository serves as a simple archive of **medical prescription samples** collected over time.  

It includes:
- Handwritten and printed prescriptions from doctors/hospitals
- Examples in English and regional Indian languages (Kannada, Bengali, Assamese, etc.)
- Screenshots possibly from pharmacy/dawaikhana apps or digital prescription platforms
- Various layouts and formats used in India (government hospitals, private clinics, emergency prescriptions, etc.)

**Note**: All images appear to be publicly shared or anonymized samples. **No personal patient information should be identifiable** — if any image unintentionally contains sensitive data, please open an issue.

## What's inside

- **~100 image files** (jpg, jpeg, png, webp)
- Examples from prestigious institutions (e.g. AIIMS New Delhi emergency prescription)
- Prescriptions in multiple Indian scripts/languages
- Mobile app screenshots (possibly related to e-prescription or medicine ordering systems)
- Drug labels, dosage instructions, and related visuals

No code, datasets, OCR models, or structured data — just raw images for reference, research, or curiosity.

## Languages / Regions visible

- English (most common)
- **Kannada**
- **Bengali**
- **Assamese**
- **Urdu**
- **Hindi** (Devanagari) in some images

## Usage ideas

People sometimes use collections like this for:

- Studying handwriting variation in medical prescriptions
- Training/testing OCR models for handwritten prescriptions in Indian languages
- Understanding prescription formats in different Indian states
- Pharmacy / medical app UI/UX reference
- Educational purposes (pharmacy students, medical documentation training)

## Important Legal & Ethical Notes

- These images are believed to be shared publicly or anonymized.
- **Do not use for any malicious purpose** (fraud, forgery, etc.).
- If you are a patient/doctor and recognize your own prescription and want it removed → open an issue with the filename and it will be deleted promptly.
- Not medical advice — never use these images to self-medicate or recreate prescriptions.
